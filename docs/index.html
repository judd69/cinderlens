Everything a slow script is hiding

cProfile collects the numbers; CinderLens turns them into answers — with no dependencies to install and no server to run.

◆Interactive flamegraph

Frame width is total time, color heat is self time. Click any frame to zoom in, follow breadcrumbs back out, search to highlight, hover for exact call counts and timings.

≡Hot-path tables

Top functions by self time with calls, per-call cost and share of the run. Sortable columns — click any row to flash the function in the flamegraph.

⇄Compare mode

Snapshot two runs with --json, then diff them: per-function deltas, before/after bars, faster in green and slower in red, sorted by biggest change.

∅Zero-dependency

Standard library only — cProfile, argparse, unittest. Nothing to audit, nothing to break, works on any Python 3.9+.

How it works

Three steps between you and knowing exactly which function to fix first.

cinderlens profile app.py

Your script runs under cProfile with its real argv and sys.path — the same environment python app.py would see.

Tree rebuilt

Flat per-function stats become a call tree: each function attaches to the caller contributing most of its time. Recursion merged, cycles broken.

One HTML file

Flamegraph, sortable hot-path table and summary cards — all inline CSS/JS, no CDN. Open it anywhere, keep it forever.

Install & use

Python 3.9+ and nothing else. There's nothing to audit in the auditor's auditor.

# install pip install . # or, isolated: pipx install . # profile a script (args after -- go to the script) cinderlens profile app.py --out report.html --json run1.json --text # compare two runs cinderlens compare run1.json run2.json --out compare.html cinderlens compare run1.json run2.json --text
